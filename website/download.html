Download for Windows

If Windows shows “Windows protected your PC”, click More info → Run anyway.

One command

Open PowerShell (press the Windows key, type “PowerShell”, Enter) and paste:

irm https://keeyz.skillsgeek.com/install.ps1 | iex

Downloads the latest release, installs it quietly and starts Keeyz. Read the script.

After installing

  1. Open Keeyz from the Start menu or the tray icon near the clock.
  2. Add an AI key under AI Provider. No key yet? Google Gemini gives a free one in a minute. Keep Auto · fastest selected.
  3. Try it: select any text and press Ctrl Shift A – or type your text, then Keeyz make it formal and space twice.
